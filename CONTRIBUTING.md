# Contributing

Bug reports, ideas and pull requests are welcome.

- **Bugs:** open an issue with your macOS version, what you did, what you expected and what happened.
  A screenshot or screen recording helps.
- **Pull requests:** keep each one to a single change. Run `scripts/build.sh` and the offline checks
  in the README before opening it, and describe how you tested anything the checks don't cover
  (such as live capture or multiple displays).
- **Style:** match the surrounding code. Glimpse uses AppKit, ScreenCaptureKit and the system
  frameworks only; please don't add third-party dependencies without discussing it in an issue first.
